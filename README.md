# 被抹掉的现场 · 解密档案

《被抹掉的现场》的「档案」式可视化单页站点。纯静态 HTML、零依赖、可直接托管于 GitHub Pages。

## 这是什么

一本被「揭开一角」的档案：黄巾起义疑点重重，张角三兄弟能看见被篡改历史的痕迹。
站点以「解密档案」的视觉语言呈现小说设定与连载进度——访客能看到的，只有这卷被揭开一角的卷宗。

## 包含内容

- 六卷总纲时间轴
- 角色群像（密文悬停显影）
- 世界法则 / 力量体系（加密区块）
- 章节进度 · 已规划至 15 章（当前 6/15）
- 待回收伏笔、后续方向

## 门禁与解封节奏

- **解封前**：访客仅见书名、简介、预定解封日期（2026-09-23）与实时倒计时。
- **上线日（09-23）起**：自动公开卷壹前三章，其余内容以「待逐章解封」呈现。
- **管理员入口**：持有口令可解锁完整档案（含加密设定区块），会话内有效。
- 计时以授时中心为基准（多源授时取中位数），避免本机时间篡改导致的提前解封。

## 技术

- 单文件 `index.html`，无构建、无外部依赖。
- 加密区块采用 XOR + SHA-256 派生密钥流；内容随连载逐章放出，作者喂入记忆文件后更新。
